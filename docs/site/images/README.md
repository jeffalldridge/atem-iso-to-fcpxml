# Website Images

The screenshots are lossless Retina window captures (`screencapture -l <window> -o -x`) of the Mac app on October 21, 2026, showing a synthetic "Live Show" recording made from generated media headers. No real footage, names, or paths appear in them.

1. `01-open.png`: the empty window that accepts a dropped recording.
2. `02-choices.png`: cameras, soundtrack, extra audio, and options for the demo recording.
3. `03-done.png`: the completed conversion with Open in Final Cut Pro.

Recapture them from the real app whenever the window changes. Do not add vendor application icons or artwork to the site; the favicon and the app icon are the project's own.
