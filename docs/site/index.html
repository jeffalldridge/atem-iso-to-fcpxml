From Recording to Final Cut.

  1. Choose Your Recording

    Mount your SSD. Right-click the native ATEM .drp file or its folder, then choose Quick Actions → ATEM ISO to FCPXML.

  2. Select Cameras and Audio

    Select the camera inputs you used and a WAV for the soundtrack. Add mic inputs as separate audio angles, or leave them out.

  3. Import into Final Cut

    Import the new .fcpxml for a multicam clip, your live edit, and the selected footage. Your original files stay untouched.

What Carries Over

Cuts stay editable. Some effects use the program recording or an approximation.

Installation

  1. Download and unzip ATEM-ISO-to-FCPXML-Quick-Action.zip from the release page.
  2. Double-click ATEM ISO to FCPXML.workflow and choose Install.
  3. Right-click a recording in Finder to run it.

Requires Python 3.9 or newer. Install Apple’s Command Line Tools with xcode-select --install, or use Python for macOS.

Prefer the terminal? Use the Python script.

Questions

Does It Use the WAV Files?

Each camera uses its matching WAV when available, or MP4 audio otherwise. Choose one soundtrack for the live edit. Mic inputs can be added as separate audio angles.

Can I Rename My Recording or Inputs?

Yes. Custom input labels and a renamed recording folder work. Keep the files and subfolders inside the recording intact. Use the .drp written by the ATEM; projects exported from Resolve are a different format.

Where Does the Footage Go?

The tool writes one .fcpxml beside your .drp without changing or uploading the recording. Final Cut’s import settings determine whether footage is copied or linked. Keep the SSD connected while copying, or while editing linked footage.

Will It Import into My Selected Event?

Import creates a new event with the multicam, project, and source clips. You can move them to another event afterward.

What Should I Check Before Exporting?

Check sync, the end of the recording, and marked effects. Timing mismatches are flagged but not corrected. If the program recording is missing, the first camera stands in for keyed sections, with a marker. Media Player changes during recording may be missing.
